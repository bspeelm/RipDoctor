# Review

One packet per release: what changed, what was read, and what was run.

A packet is written when a version is tagged. It names the load-bearing surfaces
touched — anything that receives bytes, executes a process, deletes a file or
enforces a gate — and records that a human read them at that commit, along with
the checks that were executed and their output.

It is allowed to show debt. A surface nobody has read is listed as unread;
honesty about that is the point, and a packet claiming a clean sweep it did not
do is worse than no packet.
