# 0.3.0 — audio that was not recorded here

Tagged from `main`. Fourteen commits since 0.2.0.

## What changed

A record can now be created from a file instead of a turntable. The file is
uploaded from the browser in pieces, verified, re-encoded to FLAC and placed as
a side; everything after that — first pass, ear check, cut, import, archive —
is the path that already existed, unchanged.

Also in this release: `docs/north-star.md`, which the project had been running
without, and the three other artefacts the development standard asks for.

Decisions: ADR-052 (the code ceiling moves to 7,400, and what that supersedes),
ADR-053 (how a file becomes a side).

## Load-bearing surfaces touched

Per the standard's §2.3 list. Both of these are new answers to the exit exam's
question about how bytes enter the machine.

| surface | what is new | the gate on it |
|---|---|---|
| **Receives bytes from a network** | the four ingest routes | size and ceiling checks before anything is written; an offset that must follow the scratch file; a decode of the whole stream before the file is placed |
| **Executes external processes** | `ffprobe` twice and one `ffmpeg` encode per upload | argv built by one function per call, each asserted by a test; everything through the existing runner seam |

Neither adds a path that writes outside the pool, deletes a file it did not
create, or touches a credential.

## What was executed

- `make check` on every commit: format, lint, types, 1073 tests, budgets.
- CI on 3.11, 3.12 and 3.13 green on all fourteen. This workstation's 3.14
  segfaults intermittently (ADR-019) and is not the authority.
- `../agent-context/check.sh`: 15 ok, 0 failed, 0 gate artefacts missing.
- One real album end to end on the deployed server: a 505 MB, 77-minute file
  uploaded, normalised, verified, cut, imported and archived. The archived side
  reads 48 kHz stereo, decodes under `flac -t`, carries a correct duration
  rather than `0.000`, and carries no tags but the encoder line — which is the
  two ffmpeg flags proving themselves on a real file rather than on a fake.

## What was not verified

- **The browser.** There was no browser tooling available while this was built.
  The added JavaScript was parsed with an ES parser and every element id is
  present in the served page, but the layout and the console were checked by the
  author on the deployed build, not by a command.
- **A gapless source.** The fit falls back to catalogue durations when there are
  no gaps to snap to. Expected, documented, and not exercised here.
- **Resuming an interrupted upload.** The offset logic has unit tests; a real
  interrupted transfer was not staged.

## Debt this release did not clear

- The trim ADR-036 promised. ADR-052 declines to do it under pressure to free a
  specific number and says so; it is still owed.
- Issue #19: a body over the adapter's ceiling desyncs a keep-alive connection.
  Pre-existing; the ingest's pieces never approach it.
- Issue #24: installing artwork resets every track to 0600, undoing the
  importer's mode fix. Pre-existing, found while verifying this release on a
  live library.
