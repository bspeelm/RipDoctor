# History

Shipped plans, retired documents, and prose that has stopped being true.

A plan that has been executed belongs here rather than in the working set: it
describes a decision already taken, and a reader looking for what the project
does now should not have to work out which of two documents is current.

Nothing here is maintained. It is kept because the reasoning behind a shipped
change is worth being able to find, and because the prose budget in
`scripts/budgets.py` exempts this directory — retiring a document is how that
budget is met, rather than raising it.
